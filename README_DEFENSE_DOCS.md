## ⏱️ Presentation Timing

**Per Question**: 2-3 minutes
- 30 seconds: State the question/concern
- 90 seconds: Present main answer (read table)
- 30-60 seconds: State commitment/action plan

**Total Time**: 6-9 minutes for all three questions

**Tips**:
- Practice with a timer
- Don't rush through tables
- Pause for committee to absorb information
- Be ready for follow-up questions
- Stay calm and confident
